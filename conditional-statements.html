Conditional Statements in Python

Make decisions in your programs

Introduction to Decision Making

Conditional statements allow programs to make decisions and execute different code based on conditions. They are fundamental to creating intelligent, responsive programs.

Why Conditional Statements?

  • Make programs interactive and responsive
  • Execute different code based on user input
  • Handle different scenarios automatically
  • Implement business logic and rules

if Statement

Basic if Statement

The if statement executes code only when a condition is True.

Syntax:

if condition:
    # code to execute if condition is True
    statement1
    statement2

Example 1: Check Voting Eligibility

age = 20

if age >= 18:
    print("You are eligible to vote")
    print("Please register if you haven't")
Output: 
You are eligible to vote
Please register if you haven't

Example 2: Check Positive Number

number = 15

if number > 0:
    print(f"{number} is a positive number")
Output: 
15 is a positive number

Example 3: Password Check

password = input("Enter password: ")

if len(password) >= 8:
    print("Password length is acceptable")
    
if password.isalnum():
    print("Password contains only letters and numbers")

if-else Statement

if-else Structure

The if-else statement provides an alternative path when the condition is False.

Syntax:

if condition:
    # code if condition is True
else:
    # code if condition is False

Example 1: Even or Odd

number = int(input("Enter a number: "))

if number % 2 == 0:
    print(f"{number} is even")
else:
    print(f"{number} is odd")

Example 2: Pass or Fail

marks = 65

if marks >= 40:
    print("Congratulations! You passed")
    print(f"Your marks: {marks}")
else:
    print("Sorry, you failed")
    print(f"Your marks: {marks}")
    print("Better luck next time")

Example 3: Discount Eligibility

total_purchase = 1500

if total_purchase >= 1000:
    discount = total_purchase * 0.10
    final_amount = total_purchase - discount
    print(f"Discount: ₹{discount}")
    print(f"Final Amount: ₹{final_amount}")
else:
    print(f"No discount. Total: ₹{total_purchase}")
    print("Shop for ₹1000 or more to get 10% discount")

if-elif-else Ladder

Multiple Conditions

The elif (else if) allows checking multiple conditions in sequence.

Syntax:

if condition1:
    # code if condition1 is True
elif condition2:
    # code if condition2 is True
elif condition3:
    # code if condition3 is True
else:
    # code if all conditions are False

Example 1: Grade Calculator

marks = 85

if marks >= 90:
    grade = "A+"
    print("Excellent!")
elif marks >= 80:
    grade = "A"
    print("Very Good!")
elif marks >= 70:
    grade = "B"
    print("Good!")
elif marks >= 60:
    grade = "C"
    print("Average")
elif marks >= 40:
    grade = "D"
    print("Pass")
else:
    grade = "F"
    print("Fail")

print(f"Your grade: {grade}")
Output: 
Very Good!
Your grade: A

Example 2: Traffic Light System

light = input("Enter traffic light color: ").lower()

if light == "red":
    print("STOP! Do not cross")
elif light == "yellow":
    print("WAIT! Prepare to stop")
elif light == "green":
    print("GO! You can cross")
else:
    print("Invalid color")

Example 3: BMI Calculator

weight = float(input("Enter weight (kg): "))
height = float(input("Enter height (m): "))

bmi = weight / (height ** 2)

print(f"Your BMI: {bmi:.2f}")

if bmi < 18.5:
    print("Category: Underweight")
elif bmi < 25:
    print("Category: Normal weight")
elif bmi < 30:
    print("Category: Overweight")
else:
    print("Category: Obese")

Nested Conditional Statements

Conditions Within Conditions

Nested conditionals are if statements inside other if statements, allowing complex decision-making.

Example 1: Loan Eligibility

age = 30
income = 50000
credit_score = 750

if age >= 21:
    if income >= 30000:
        if credit_score >= 700:
            print("Loan Approved!")
            print("You meet all criteria")
        else:
            print("Loan Rejected: Low credit score")
    else:
        print("Loan Rejected: Insufficient income")
else:
    print("Loan Rejected: Age below 21")

Example 2: Movie Ticket Pricing

age = int(input("Enter your age: "))
day = input("Enter day (weekday/weekend): ").lower()

if age < 12:
    if day == "weekday":
        price = 100
    else:
        price = 150
    print(f"Child ticket: ₹{price}")
elif age >= 60:
    if day == "weekday":
        price = 120
    else:
        price = 180
    print(f"Senior citizen ticket: ₹{price}")
else:
    if day == "weekday":
        price = 200
    else:
        price = 300
    print(f"Adult ticket: ₹{price}")

⚠️ Best Practice

Avoid too many nested levels (more than 3). Use logical operators (and, or) instead:

# Instead of nested if:
if age >= 21:
    if income >= 30000:
        if credit_score >= 700:
            print("Approved")

# Use logical operators:
if age >= 21 and income >= 30000 and credit_score >= 700:
    print("Approved")

Assessment

Question 1

Write a program to check if a number is positive, negative, or zero.

Show Solution 
number = float(input("Enter a number: "))

if number > 0:
    print("Positive number")
elif number < 0:
    print("Negative number")
else:
    print("Zero")

Question 2

Create a program to find the largest of three numbers.

Show Solution 
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
c = int(input("Enter third number: "))

if a >= b and a >= c:
    print(f"Largest: {a}")
elif b >= a and b >= c:
    print(f"Largest: {b}")
else:
    print(f"Largest: {c}")

Question 3

Write a program to check if a year is a leap year.

Show Solution 
year = int(input("Enter year: "))

if year % 4 == 0:
    if year % 100 == 0:
        if year % 400 == 0:
            print(f"{year} is a leap year")
        else:
            print(f"{year} is not a leap year")
    else:
        print(f"{year} is a leap year")
else:
    print(f"{year} is not a leap year")
