Hour 1: Algorithmic Thinking

What is an Algorithm?

An algorithm is a step-by-step procedure to solve a problem. It's like a recipe that tells the computer exactly what to do.

Real-World Example: Making Tea

  1. Boil water
  2. Add tea leaves
  3. Add sugar
  4. Stir well
  5. Strain and serve

This is an algorithm! Clear steps that anyone can follow.

Characteristics of a Good Algorithm:

  • Input: Takes zero or more inputs
  • Output: Produces at least one output
  • Definiteness: Each step is clear and unambiguous
  • Finiteness: Must terminate after finite steps
  • Effectiveness: Steps must be basic enough to execute

Example 1: Algorithm to Find Maximum

# Algorithm in plain English:
# 1. Start with first number as maximum
# 2. Compare each remaining number with maximum
# 3. If number is greater, update maximum
# 4. Return maximum

def find_maximum(numbers):
    """Find maximum number in list"""
    if not numbers:
        return None
    
    max_num = numbers[0]  # Step 1
    
    for num in numbers[1:]:  # Step 2
        if num > max_num:  # Step 3
            max_num = num
    
    return max_num  # Step 4

# Test
numbers = [45, 23, 67, 12, 89, 34]
print(f"Numbers: {numbers}")
print(f"Maximum: {find_maximum(numbers)}")
Output: 
Numbers: [45, 23, 67, 12, 89, 34]
Maximum: 89

Example 2: Algorithm to Check Even/Odd

# Algorithm:
# 1. Take a number as input
# 2. Divide number by 2
# 3. If remainder is 0, it's even
# 4. Otherwise, it's odd

def check_even_odd(number):
    """Check if number is even or odd"""
    if number % 2 == 0:
        return "Even"
    else:
        return "Odd"

# Test
for num in [10, 15, 22, 37]:
    result = check_even_odd(num)
    print(f"{num} is {result}")

Example 3: Algorithm Representation - Pseudocode

# Pseudocode for Sum of N numbers
"""
Algorithm: SumOfN
Input: n (positive integer)
Output: sum of numbers from 1 to n

BEGIN
    sum = 0
    FOR i = 1 TO n DO
        sum = sum + i
    END FOR
    RETURN sum
END
"""

# Python implementation
def sum_of_n(n):
    """Calculate sum of numbers from 1 to n"""
    total = 0
    for i in range(1, n + 1):
        total += i
    return total

# Test
n = 10
print(f"Sum of 1 to {n} = {sum_of_n(n)}")
Output: 
Sum of 1 to 10 = 55

Example 4: Why Algorithms Matter

# Problem: Find if number exists in list

# Approach 1: Linear Search (Simple)
def linear_search(numbers, target):
    for i, num in enumerate(numbers):
        if num == target:
            return i
    return -1

# Approach 2: Binary Search (Efficient - requires sorted list)
def binary_search(numbers, target):
    left, right = 0, len(numbers) - 1
    
    while left <= right:
        mid = (left + right) // 2
        if numbers[mid] == target:
            return mid
        elif numbers[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

# Test
numbers = [2, 5, 8, 12, 16, 23, 38, 45, 56, 67, 78]
target = 23

print(f"Linear search: Found at index {linear_search(numbers, target)}")
print(f"Binary search: Found at index {binary_search(numbers, target)}")

Hour 2: Time & Space Complexity

What is Time Complexity?

Time complexity measures how the runtime of an algorithm grows as the input size increases. It helps us compare algorithms.

Why It Matters:

Imagine searching for a name in a phone book:

  • Method 1: Check every page from start (slow for large books)
  • Method 2: Use alphabetical order to jump to section (fast)

Time complexity helps us choose Method 2!

Space Complexity:

Space complexity measures how much memory an algorithm uses. Important when memory is limited.

Big-O Notation

Big-O describes the upper bound of time/space complexity. It shows worst-case scenario.

Example 5: O(1) - Constant Time

def access_element(arr, index):

def add_to_dict(dictionary, key, value):
    """Dictionary operations are O(1)"""

Example 6: O(n) - Linear Time

def sum_array(arr):
    """Must visit each element once - O(n)"""
    total = 0
    for num in arr:
        total += num
    return total

def print_all(arr):
    """Printing all elements - O(n)"""
    for element in arr:
        print(element)

# Time grows linearly with input size
numbers = [1, 2, 3, 4, 5]
print(f"Sum: {sum_array(numbers)}")

Example 7: O(n²) - Quadratic Time

def print_pairs(arr):
    """Nested loops - O(n²)"""
    for i in arr:
        for j in arr:
            print(f"({i}, {j})")

def bubble_sort(arr):
    """Bubble sort - O(n²)"""
    n = len(arr)
    for i in range(n):
        for j in range(n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

# Test
numbers = [64, 34, 25, 12, 22]
print(f"Original: {numbers}")
print(f"Sorted: {bubble_sort(numbers.copy())}")

Example 8: Comparing Algorithms

import time

# Slow: O(n²)
def find_duplicates_slow(arr):
    duplicates = []
    for i in range(len(arr)):
        for j in range(i + 1, len(arr)):
            if arr[i] == arr[j] and arr[i] not in duplicates:
                duplicates.append(arr[i])
    return duplicates

# Fast: O(n)
def find_duplicates_fast(arr):
    seen = set()
    duplicates = set()
    for num in arr:
        if num in seen:
            duplicates.add(num)
        seen.add(num)
    return list(duplicates)

# Test
numbers = [1, 2, 3, 2, 4, 5, 3, 6, 7, 8, 9, 1]
print(f"Duplicates: {find_duplicates_fast(numbers)}")

Example 9: Space Complexity

# O(1) Space - Constant
def sum_iterative(n):
    """Uses only one variable"""
    total = 0
    for i in range(1, n + 1):
        total += i
    return total

# O(n) Space - Linear
def sum_recursive(n):
    """Each call uses stack space"""
    if n == 0:
        return 0
    return n + sum_recursive(n - 1)

# O(n) Space - Creating new list
def create_squares(n):
    """Stores n elements"""
    return [i ** 2 for i in range(n)]

# Test
print(f"Sum (iterative): {sum_iterative(10)}")
print(f"Squares: {create_squares(5)}")

Example 10: Best, Average, Worst Case

def linear_search_analysis(arr, target):
    """
    Best case: O(1) - target is first element
    Average case: O(n/2) = O(n) - target in middle
    Worst case: O(n) - target is last or not present
    """
    for i, element in enumerate(arr):
        if element == target:
            return i
    return -1

# Test different cases
numbers = [10, 20, 30, 40, 50]

# Best case
print(f"Best case (first): {linear_search_analysis(numbers, 10)}")

# Average case
print(f"Average case (middle): {linear_search_analysis(numbers, 30)}")

# Worst case
print(f"Worst case (last): {linear_search_analysis(numbers, 50)}")
print(f"Worst case (not found): {linear_search_analysis(numbers, 100)}")

Key Takeaways

  • Algorithm is a step-by-step procedure to solve problems
  • Good algorithms are definite, finite, and effective
  • Time complexity measures how runtime grows with input
  • Space complexity measures memory usage
  • Big-O notation describes worst-case complexity
  • Common complexities: O(1), O(log n), O(n), O(n log n), O(n²)
  • O(1) is fastest, O(2^n) is slowest
  • Choose algorithms based on input size and requirements
  • Analyze best, average, and worst cases
  • Efficient algorithms are crucial for scalable applications
