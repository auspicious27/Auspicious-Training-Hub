## Quick Tips

### To Add Content
1. Use `<div class="topic">` for each topic
2. Use `<div class="example-box">` for examples
3. Use `<pre><code class="language-python">` for code
4. Copy assessment structure from Day 1 or Day 2

### To Change Colors
Edit in `styles.css`:
```css
:root {
    --gradient-start: #fc359e;  /* Change this */
    --gradient-end: #ff8b78;    /* Change this */
}
```

### To Add More Examples
Copy this structure:
```html
<div class="detailed-example">
    <h4>Example Title</h4>
    <pre><code class="language-python">
# Your code here
print("Hello")
    </code></pre>
    <div class="output-box">
        <strong>Output:</strong>
        <pre>Hello</pre>
    </div>
</div>
```

## Common Questions

**Q: How do I add more days?**
A: Copy `day1.html`, rename it, update the content and navigation links.

**Q: Can I change the gradient colors?**
A: Yes! Edit the CSS variables in `styles.css`.

**Q: How do I add images?**
A: Create an `images` folder and use `<img src="images/yourimage.png">`.

**Q: Is this mobile-friendly?**
A: Yes! The design is fully responsive.

**Q: Can I add videos?**
A: Yes! Use `<video>` or embed YouTube videos.
