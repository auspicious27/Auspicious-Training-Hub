Hour 1: Arrays

What is an Array?

An array is a collection of elements stored in contiguous memory locations. All elements are of the same type and accessed using an index.

Real-World Analogy:

Think of an array like a row of mailboxes:

  • Each mailbox has a number (index)
  • All mailboxes are in a line (contiguous)
  • Each holds one item (element)
  • You can directly access any mailbox by its number

Array Memory Representation:

Array: [10, 20, 30, 40, 50]
Index:   0   1   2   3   4

Memory: [10][20][30][40][50]
Address: 1000 1004 1008 1012 1016

Elements are stored in consecutive memory locations.

Example 1: Creating and Accessing Arrays

# Create array (list in Python)
numbers = [10, 20, 30, 40, 50]
fruits = ["apple", "banana", "cherry"]

# Access elements
print(f"First number: {numbers[0]}")
print(f"Last number: {numbers[-1]}")
print(f"Second fruit: {fruits[1]}")

# Array length
print(f"Array size: {len(numbers)}")
Output: 
First number: 10
Last number: 50
Second fruit: banana
Array size: 5

Advantages of Arrays:

  • Fast access: O(1) time to access any element
  • Memory efficient: Contiguous storage
  • Cache friendly: Better performance
  • Simple: Easy to understand and use

Limitations of Arrays:

  • Fixed size: Cannot grow dynamically (in some languages)
  • Insertion/Deletion: Expensive operations
  • Wasted space: If not fully utilized

Array Operations

Example 2: Array Traversal

def traverse_array(arr):
                    """Visit each element - O(n)"""
    print("Array elements:")
    for i in range(len(arr)):
        print(f"Index {i}: {arr[i]}")

Example 3: Array Insertion

# Insert at end - O(1)
def insert_at_end(arr, element):
    arr.append(element)
    return arr

# Insert at beginning - O(n)
def insert_at_beginning(arr, element):
    arr.insert(0, element)
    return arr

# Insert at specific position - O(n)
def insert_at_position(arr, index, element):
    arr.insert(index, element)
    return arr

# Test
numbers = [10, 20, 30, 40]
print(f"Original: {numbers}")

insert_at_end(numbers, 50)
print(f"After insert at end: {numbers}")

insert_at_position(numbers, 2, 25)
print(f"After insert at index 2: {numbers}")
Output: 
Original: [10, 20, 30, 40]
After insert at end: [10, 20, 30, 40, 50]
After insert at index 2: [10, 20, 25, 30, 40, 50]

Example 4: Array Deletion

# Delete by value - O(n)
def delete_by_value(arr, value):
    if value in arr:
        arr.remove(value)
    return arr

# Delete by index - O(n)
def delete_by_index(arr, index):
    if 0 <= index < len(arr):
        del arr[index]
    return arr

# Delete last element - O(1)
def delete_last(arr):
    if arr:
        arr.pop()
    return arr

# Test
numbers = [10, 20, 30, 40, 50]
print(f"Original: {numbers}")

delete_by_value(numbers, 30)
print(f"After deleting 30: {numbers}")

delete_by_index(numbers, 0)
print(f"After deleting index 0: {numbers}")

Example 5: Array Update

def update_element(arr, index, new_value):
    """Update element at index - O(1)"""
    if 0 <= index < len(arr):
        arr[index] = new_value
        return True
    return False

# Test
numbers = [10, 20, 30, 40, 50]
print(f"Original: {numbers}")

Hour 2: Searching Algorithms

Linear Search

Linear search checks each element sequentially until the target is found or the end is reached.

Algorithm:

  1. Start from first element
  2. Compare with target
  3. If match found, return index
  4. If not, move to next element
  5. Repeat until found or end reached

Example 6: Linear Search Implementation

def linear_search(arr, target):
    """
    Linear Search Algorithm
    Time Complexity: O(n)
    Space Complexity: O(1)
    """
    for i in range(len(arr)):
        if arr[i] == target:
            return i  # Found at index i
    return -1  # Not found

# Test
numbers = [64, 34, 25, 12, 22, 11, 90]
target = 22

result = linear_search(numbers, target)
if result != -1:
    print(f"Element {target} found at index {result}")
else:
    print(f"Element {target} not found")
Output: 
Element 22 found at index 4

Example 7: Linear Search with Count

def linear_search_all(arr, target):
    """Find all occurrences of target"""
    indices = []
    for i in range(len(arr)):
        if arr[i] == target:
            indices.append(i)
    return indices

# Test
numbers = [10, 20, 30, 20, 40, 20, 50]
target = 20

indices = linear_search_all(numbers, target)
print(f"Element {target} found at indices: {indices}")
Output: 
Element 20 found at indices: [1, 3, 5]

Linear Search Complexity:

  • Best Case: O(1) - element at first position
  • Average Case: O(n/2) = O(n)
  • Worst Case: O(n) - element at last or not present
  • Space: O(1) - no extra space needed

Binary Search

Binary search is an efficient algorithm that works on sorted arrays by repeatedly dividing the search interval in half.

⚠️ Important Prerequisite:

Binary search only works on sorted arrays!

Algorithm:

  1. Find middle element
  2. If middle == target, return index
  3. If target < middle, search left half
  4. If target > middle, search right half
  5. Repeat until found or no elements left

Example 8: Binary Search Implementation

def binary_search(arr, target):
    """
    Binary Search Algorithm
    Time Complexity: O(log n)
    Space Complexity: O(1)
    Prerequisite: Array must be sorted
    """
    left = 0
    right = len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        if arr[mid] == target:
            return mid  # Found
        elif arr[mid] < target:
            left = mid + 1  # Search right half
        else:
            right = mid - 1  # Search left half
    
    return -1  # Not found

# Test
numbers = [11, 12, 22, 25, 34, 64, 90]  # Must be sorted!
target = 25

result = binary_search(numbers, target)
if result != -1:
    print(f"Element {target} found at index {result}")
else:
    print(f"Element {target} not found")
Output: 
Element 25 found at index 3

Example 9: Binary Search Recursive

def binary_search_recursive(arr, target, left, right):
    """Recursive implementation of binary search"""
    if left > right:
        return -1  # Base case: not found
    
    mid = (left + right) // 2
    
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search_recursive(arr, target, mid + 1, right)
    else:
        return binary_search_recursive(arr, target, left, mid - 1)

# Test
numbers = [11, 12, 22, 25, 34, 64, 90]
target = 64

result = binary_search_recursive(numbers, target, 0, len(numbers) - 1)
print(f"Element {target} found at index {result}")

Example 10: Comparing Search Algorithms

import time

def compare_searches(arr, target):
    """Compare linear and binary search"""
    # Linear search
    start = time.time()
    linear_result = linear_search(arr, target)
    linear_time = time.time() - start
    
    # Binary search (array must be sorted)
    arr_sorted = sorted(arr)
    start = time.time()
    binary_result = binary_search(arr_sorted, target)
    binary_time = time.time() - start
    
    print(f"Linear Search: Found at {linear_result}, Time: {linear_time:.6f}s")
    print(f"Binary Search: Found at {binary_result}, Time: {binary_time:.6f}s")

# Test with large array
numbers = list(range(1, 100001))
target = 99999

compare_searches(numbers, target)

Linear vs Binary Search:

Feature Linear Search Binary Search
Time Complexity O(n) O(log n)
Prerequisite None Sorted array
Best For Small/unsorted arrays Large sorted arrays
Implementation Simple Moderate

Question 1: Array Access

Answer: O(1)

Explanation: Direct access using index is constant time.

Question 2: Array Memory

How are array elements stored in memory?

Answer: Contiguous locations

Explanation: Array elements are stored in consecutive memory addresses.

Question 3: Linear Search

What is the worst-case time complexity of linear search?

Answer: O(n)

Explanation: May need to check all n elements.

Question 4: Binary Search Prerequisite

What condition must be met for binary search?

Answer: Array must be sorted

Explanation: Binary search only works on sorted arrays.

Question 5: Binary Search Complexity

What is the time complexity of binary search?

Answer: O(log n)

Explanation: Divides search space in half each time.

Question 6: Array Insertion

What is the time complexity of inserting at the beginning of an array?

Answer: O(n)

Explanation: Need to shift all existing elements.

Question 7: Search Comparison

Which is faster for large sorted arrays?

Answer: Binary search

Explanation: O(log n) is much faster than O(n) for large inputs.

Question 8: Array Advantage

What is the main advantage of arrays?

Answer: Fast random access

Explanation: Can access any element in O(1) time using index.

Question 9: Linear Search Use

When should you use linear search over binary search?

Answer: For unsorted or small arrays

Explanation: Linear search works on any array, no sorting needed.

Question 10: Array Limitation

What is a major limitation of arrays?

Answer: Fixed size (in some languages)

Explanation: Arrays have fixed size and expensive insertion/deletion.

Key Takeaways

  • Arrays store elements in contiguous memory
  • Array access is O(1) - very fast
  • Insertion/deletion can be O(n) - expensive
  • Linear search checks each element sequentially - O(n)
  • Binary search divides search space in half - O(log n)
  • Binary search requires sorted array
  • Use linear search for small/unsorted arrays
  • Use binary search for large sorted arrays
  • Arrays are cache-friendly and memory efficient
  • Choose data structure based on use case
