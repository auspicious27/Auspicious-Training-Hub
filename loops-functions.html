Loops and Functions in Python

Master repetition and code reusability

for Loop

Introduction to for Loop

The for loop iterates over a sequence (list, tuple, string, or range).

Syntax:

for variable in sequence:
    # code to execute

Example 1: Print Numbers 1 to 5

for i in range(1, 6):
    print(i)
Output:
1
2
3
4
5

Example 2: Iterate Over String

name = "Python"
for char in name:
    print(char)

Example 3: Sum of Numbers

total = 0
for num in range(1, 11):
    total += num
print(f"Sum: {total}")
Output:
Sum: 55

while Loop

Introduction to while Loop

The while loop executes as long as a condition is True.

Syntax:

while condition:
    # code to execute

Example 1: Count to 5

count = 1
while count <= 5:
    print(count)
    count += 1

Example 2: Password Validator

password = ""
while password != "python123":
    password = input("Enter password: ")
print("Access granted!")

Loop Control Statements

break, continue, pass

break - Exit Loop

for i in range(1, 11):
    if i == 5:
        break
    print(i)

continue - Skip Iteration

for i in range(1, 6):
    if i == 3:
        continue
    print(i)

pass - Placeholder

for i in range(5):
    if i == 2:
        pass  # Do nothing
    print(i)

Functions

Defining and Calling Functions

Syntax:

def function_name(parameters):
    # code
    return value

Example 1: Simple Function

def greet():
    print("Hello, World!")

greet()  # Call function

Example 2: Function with Parameters

def greet_person(name):
    print(f"Hello, {name}!")

greet_person("Alice")

Example 3: Function with Return

def add(a, b):
    return a + b

result = add(5, 3)
print(result)  # 8

Example 4: Default Parameters

def power(base, exponent=2):
    return base ** exponent

print(power(5))      # 25
print(power(5, 3))   # 125

Variable Scope

Local vs Global Variables

Local Variable

def my_function():
    x = 10  # Local variable
    print(x)

my_function()
# print(x)  # Error: x not defined outside function

Global Variable

x = 10  # Global variable

def my_function():
    print(x)  # Can access global

my_function()
print(x)

Modifying Global Variable

count = 0

def increment():
    global count
    count += 1

increment()
print(count)  # 1
