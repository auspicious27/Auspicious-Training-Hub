# Python, DSA & DBMS Training Program Website

A comprehensive 15-day training program covering Python programming, Data Structures & Algorithms, and Database Management Systems.

## 🎯 Project Overview

This is a professional-level educational website featuring:
- **15 Days of Structured Content** - From basics to advanced concepts
- **Detailed Explanations** - Every concept explained thoroughly
- **Code Examples** - Practical implementations for each topic
- **Interactive Assessments** - Day-wise quizzes and exercises
- **Beautiful Gradient Design** - Left-to-right gradient (#fc359e to #ff8b78)
- **Responsive Layout** - Works on all devices

## 🔧 Customization

### To Change Colors:
Edit CSS variables in `styles.css`:
```css
:root {
    --gradient-start: #fc359e;
    --gradient-end: #ff8b78;
    --dark-bg: #1a1a2e;
    --light-bg: #16213e;
}
```

### To Add More Days:
1. Copy `day1.html` or `day2.html` as template
2. Update content sections
3. Add assessment questions
4. Link from `index.html`
