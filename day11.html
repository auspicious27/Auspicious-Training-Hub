Hour 1: Stacks

What is a Stack?

A stack is a linear data structure that follows LIFO (Last In, First Out) principle. The last element added is the first one removed.

Real-World Examples:

  • Stack of plates: Add/remove from top only
  • Browser history: Back button uses stack
  • Undo feature: Last action undone first
  • Function calls: Call stack in programming

Stack Visualization:

Stack (LIFO):
    ┌───┐
    │ 3 │ ← Top (last in, first out)
    ├───┤
    │ 2 │
    ├───┤
    │ 1 │
    └───┘

Operations:
- Push: Add to top
- Pop: Remove from top
- Peek: View top element

Stack Operations:

  • push(item): Add item to top - O(1)
  • pop(): Remove and return top item - O(1)
  • peek(): View top item without removing - O(1)
  • isEmpty(): Check if stack is empty - O(1)
  • size(): Get number of elements - O(1)

Stack Implementation

Example 1: Stack Using List

class Stack:
    """Stack implementation using Python list"""
    def __init__(self):
        self.items = []
    
    def is_empty(self):
        """Check if stack is empty"""
        return len(self.items) == 0
    
    def push(self, item):
        """Add item to top of stack"""
        self.items.append(item)
        print(f"Pushed: {item}")
    
    def pop(self):
        """Remove and return top item"""
        if self.is_empty():
            return "Stack is empty"
        return self.items.pop()
    
    def peek(self):
        """View top item without removing"""
        if self.is_empty():
            return "Stack is empty"
        return self.items[-1]
    
    def size(self):
        """Get stack size"""
        return len(self.items)
    
    def display(self):
        """Display stack contents"""
        print(f"Stack: {self.items}")

# Test
stack = Stack()
stack.push(10)
stack.push(20)
stack.push(30)
stack.display()
print(f"Top element: {stack.peek()}")
print(f"Popped: {stack.pop()}")
stack.display()
Output: 
Pushed: 10
Pushed: 20
Pushed: 30
Stack: [10, 20, 30]
Top element: 30
Popped: 30
Stack: [10, 20]

Example 2: Balanced Parentheses Checker

def is_balanced(expression):
    """Check if parentheses are balanced using stack"""
    stack = []
    opening = "({["
    closing = ")}]"
    pairs = {"(": ")", "{": "}", "[": "]"}
    
    for char in expression:
        if char in opening:
            stack.append(char)
        elif char in closing:
            if not stack:
                return False
            if pairs[stack.pop()] != char:
                return False
    
    return len(stack) == 0

# Test
expressions = [
    "((()))",
    "({[]})",
    "(()",
    "({[}])"
]

for expr in expressions:
    result = "Balanced" if is_balanced(expr) else "Not Balanced"
    print(f"{expr}: {result}")
Output: 
((())): Balanced
({[]}): Balanced
((): Not Balanced
({[}]): Not Balanced

Example 3: Reverse String Using Stack

def reverse_string(text):
    """Reverse string using stack"""
    stack = []
    
    # Push all characters
    for char in text:
        stack.append(char)
    
    # Pop all characters
    reversed_text = ""
    while stack:
        reversed_text += stack.pop()
    
    return reversed_text

# Test
text = "PYTHON"
print(f"Original: {text}")
print(f"Reversed: {reverse_string(text)}")
Output: 
Original: PYTHON
Reversed: NOHTYP

Example 4: Undo Feature Simulation

class TextEditor:
    """Simple text editor with undo feature"""
    def __init__(self):
        self.text = ""
        self.history = []
    
    def write(self, text):
        """Add text and save to history"""
        self.history.append(self.text)
        self.text += text
        print(f"Current text: {self.text}")
    
    def undo(self):
        """Undo last action"""
        if self.history:
            self.text = self.history.pop()
            print(f"After undo: {self.text}")
        else:
            print("Nothing to undo")

# Test
editor = TextEditor()
editor.write("Hello ")
editor.write("World")
editor.write("!")
editor.undo()
editor.undo()

Hour 2: Queues

What is a Queue?

A queue is a linear data structure that follows FIFO (First In, First Out) principle. The first element added is the first one removed.

Real-World Examples:

  • Line at ticket counter: First person served first
  • Print queue: Documents printed in order
  • Call center: Calls answered in order
  • Task scheduling: CPU scheduling

Queue Visualization:

Queue (FIFO):
Front                    Rear
  ↓                        ↓
┌───┬───┬───┬───┐
│ 1 │ 2 │ 3 │ 4 │
└───┴───┴───┴───┘
  ↑                        ↑
Dequeue                 Enqueue
(remove)                 (add)

Operations:
- Enqueue: Add to rear
- Dequeue: Remove from front

Queue Operations:

  • enqueue(item): Add item to rear - O(1)
  • dequeue(): Remove and return front item - O(1)
  • front(): View front item - O(1)
  • rear(): View rear item - O(1)
  • isEmpty(): Check if queue is empty - O(1)

Queue Implementation

Example 5: Queue Using List

class Queue:
    """Queue implementation using Python list"""
    def __init__(self):
        self.items = []
    
    def is_empty(self):
        """Check if queue is empty"""
        return len(self.items) == 0
    
    def enqueue(self, item):
        """Add item to rear of queue"""
        self.items.append(item)
        print(f"Enqueued: {item}")
    
    def dequeue(self):
        """Remove and return front item"""
        if self.is_empty():
            return "Queue is empty"
        return self.items.pop(0)
    
    def front(self):
        """View front item"""
        if self.is_empty():
            return "Queue is empty"
        return self.items[0]
    
    def rear(self):
        """View rear item"""
        if self.is_empty():
            return "Queue is empty"
        return self.items[-1]
    
    def size(self):
        """Get queue size"""
        return len(self.items)
    
    def display(self):
        """Display queue contents"""
        print(f"Queue: {self.items}")

# Test
queue = Queue()
queue.enqueue(10)
queue.enqueue(20)
queue.enqueue(30)
queue.display()
print(f"Front: {queue.front()}")
print(f"Dequeued: {queue.dequeue()}")
queue.display()
Output: 
Enqueued: 10
Enqueued: 20
Enqueued: 30
Queue: [10, 20, 30]
Front: 10
Dequeued: 10
Queue: [20, 30]

Example 6: Print Queue Simulation

class PrintQueue:
    """Simulate printer queue"""
    def __init__(self):
        self.queue = []
    
    def add_document(self, doc_name):
        """Add document to print queue"""
        self.queue.append(doc_name)
        print(f"Added to queue: {doc_name}")
    
    def print_document(self):
        """Print next document"""
        if not self.queue:
            print("No documents in queue")
            return
        doc = self.queue.pop(0)
        print(f"Printing: {doc}")
    
    def show_queue(self):
        """Show pending documents"""
        if not self.queue:
            print("Queue is empty")
        else:
            print(f"Pending: {self.queue}")

# Test
printer = PrintQueue()
printer.add_document("Report.pdf")
printer.add_document("Invoice.pdf")
printer.add_document("Letter.pdf")
printer.show_queue()
printer.print_document()
printer.print_document()
printer.show_queue()

Example 7: Circular Queue

class CircularQueue:
    """Circular queue with fixed size"""
    def __init__(self, size):
        self.size = size
        self.queue = [None] * size
        self.front = self.rear = -1
    
    def is_full(self):
        return (self.rear + 1) % self.size == self.front
    
    def is_empty(self):
        return self.front == -1
    
    def enqueue(self, item):
        if self.is_full():
            print("Queue is full")
            return
        
        if self.front == -1:
            self.front = 0
        
        self.rear = (self.rear + 1) % self.size
        self.queue[self.rear] = item
        print(f"Enqueued: {item}")
    
    def dequeue(self):
        if self.is_empty():
            return "Queue is empty"
        
        item = self.queue[self.front]
        
        if self.front == self.rear:
            self.front = self.rear = -1
        else:
            self.front = (self.front + 1) % self.size
        
        return item

# Test
cq = CircularQueue(3)
cq.enqueue(10)
cq.enqueue(20)
cq.enqueue(30)
print(f"Dequeued: {cq.dequeue()}")
cq.enqueue(40)

Types of Queues:

  • Simple Queue: Basic FIFO queue
  • Circular Queue: Last position connects to first
  • Priority Queue: Elements have priorities
  • Deque: Double-ended queue (insert/delete from both ends)

Queue Applications:

  • CPU scheduling: Process scheduling
  • Disk scheduling: I/O request handling
  • Print spooling: Print job management
  • BFS: Breadth-first search in graphs
  • Call center: Customer service queues

Stack vs Queue:

Feature Stack Queue
Principle LIFO FIFO
Insert Push (top) Enqueue (rear)
Remove Pop (top) Dequeue (front)
Example Undo feature Print queue

Key Takeaways

  • Stack follows LIFO (Last In, First Out)
  • Queue follows FIFO (First In, First Out)
  • Stack operations: push, pop, peek - all O(1)
  • Queue operations: enqueue, dequeue - all O(1)
  • Stack used for: undo, function calls, backtracking
  • Queue used for: scheduling, print spooler, BFS
  • Circular queue reuses space efficiently
  • Priority queue serves based on priority
  • Both are linear data structures
  • Choose based on access pattern needed
