Hour 1: Dictionaries

What is a Dictionary?

A dictionary is an unordered collection of key-value pairs. Each key must be unique and maps to a value.

Real-World Analogy:

Think of a real dictionary: you look up a word (key) to find its meaning (value).

  • Phone book: Name → Phone number
  • Student records: Roll number → Student details
  • Product catalog: Product ID → Product info

Example 1: Creating Dictionaries

# Empty dictionary
empty_dict = {}

# Dictionary with data
student = {
    "name": "Alice",
    "age": 20,
    "grade": "A",
    "city": "New York"
}

# Using dict() constructor
person = dict(name="Bob", age=25, city="London")

print(f"Student: {student}")
print(f"Person: {person}")
Output: 
Student: {'name': 'Alice', 'age': 20, 'grade': 'A', 'city': 'New York'}
Person: {'name': 'Bob', 'age': 25, 'city': 'London'}

Example 2: Accessing Dictionary Values

student = {
    "name": "Alice",
    "age": 20,
    "grade": "A"
}

# Access using key
print(f"Name: {student['name']}")
print(f"Age: {student['age']}")

# Using get() method (safer)
print(f"Grade: {student.get('grade')}")
print(f"City: {student.get('city', 'Not specified')}")  # Default value
Output: 
Name: Alice
Age: 20
Grade: A
City: Not specified

Example 3: Modifying Dictionaries

student = {"name": "Alice", "age": 20}
print(f"Original: {student}")

# Add new key-value pair
student["grade"] = "A"
print(f"After adding grade: {student}")

# Modify existing value
student["age"] = 21
print(f"After updating age: {student}")

# Delete key-value pair
del student["grade"]
print(f"After deleting grade: {student}")
Output: 
Original: {'name': 'Alice', 'age': 20}
After adding grade: {'name': 'Alice', 'age': 20, 'grade': 'A'}
After updating age: {'name': 'Alice', 'age': 21, 'grade': 'A'}
After deleting grade: {'name': 'Alice', 'age': 21}

Example 4: Looping Through Dictionaries

student = {"name": "Alice", "age": 20, "grade": "A"}

# Loop through keys
print("Keys:")
for key in student:
    print(f"  {key}")

# Loop through values
print("\nValues:")
for value in student.values():
    print(f"  {value}")

# Loop through key-value pairs
print("\nKey-Value pairs:")
for key, value in student.items():
    print(f"  {key}: {value}")

Dictionary Methods

Example 5: Dictionary Methods

student = {"name": "Alice", "age": 20, "grade": "A"}

# keys() - get all keys
print(f"Keys: {list(student.keys())}")

# values() - get all values
print(f"Values: {list(student.values())}")

# items() - get key-value pairs
print(f"Items: {list(student.items())}")

# get() - safe access
print(f"Name: {student.get('name')}")
print(f"City: {student.get('city', 'Unknown')}")

Example 6: Update and Pop Methods

student = {"name": "Alice", "age": 20}
print(f"Original: {student}")

# update() - add multiple items
student.update({"grade": "A", "city": "NYC"})
print(f"After update: {student}")

# pop() - remove and return value
age = student.pop("age")
print(f"Popped age: {age}")
print(f"After pop: {student}")

# popitem() - remove last item
item = student.popitem()
print(f"Popped item: {item}")
print(f"After popitem: {student}")

Example 7: Nested Dictionaries

students = {
    "student1": {
        "name": "Alice",
        "age": 20,
        "grades": [85, 90, 88]
    },
    "student2": {
        "name": "Bob",
        "age": 21,
        "grades": [78, 82, 80]
    }
}

# Access nested data
print(f"Student1 name: {students['student1']['name']}")
print(f"Student2 grades: {students['student2']['grades']}")

# Calculate average
avg = sum(students['student1']['grades']) / len(students['student1']['grades'])
print(f"Student1 average: {avg:.2f}")

Example 8: Dictionary Comprehension

# Create dictionary of squares
squares = {x: x**2 for x in range(1, 6)}
print(f"Squares: {squares}")

# Filter dictionary
numbers = {"a": 1, "b": 2, "c": 3, "d": 4}
evens = {k: v for k, v in numbers.items() if v % 2 == 0}
print(f"Even values: {evens}")

# Transform values
prices = {"apple": 50, "banana": 30, "cherry": 80}
discounted = {k: v * 0.9 for k, v in prices.items()}
print(f"Discounted: {discounted}")

Example 9: Practical Dictionary Application

# Word frequency counter
text = "python is easy python is powerful python is fun"
words = text.split()

frequency = {}
for word in words:
    frequency[word] = frequency.get(word, 0) + 1

print("Word Frequency:")
for word, count in frequency.items():
    print(f"  {word}: {count}")
Output: 
Word Frequency:
  python: 3
  is: 3
  easy: 1
  powerful: 1
  fun: 1

Hour 2: File Handling

Why File Handling?

File handling allows programs to store data permanently. Without files, all data is lost when the program ends.

Use Cases:

  • Save user data: Settings, preferences
  • Log files: Track program activity
  • Data processing: Read CSV, JSON files
  • Configuration: Store app settings

File Open Modes:

  • 'r' - Read (default). File must exist.
  • 'w' - Write. Creates new file or overwrites existing.
  • 'a' - Append. Adds to end of file.
  • 'r+' - Read and write.
  • 'w+' - Write and read.
  • 'a+' - Append and read.

Example 1: Writing to a File

# Write mode - creates new file or overwrites
file = open("example.txt", "w")
file.write("Hello, World!\n")
file.write("This is line 2.\n")
file.write("This is line 3.")
file.close()

print("File written successfully!")

Example 2: Reading from a File

# Read entire file
file = open("example.txt", "r")
content = file.read()
file.close()

print("File content:")
print(content)
Output: 
File content:
Hello, World!
This is line 2.
This is line 3.

Example 3: Using 'with' Statement (Best Practice)

# Automatically closes file
with open("example.txt", "w") as file:
    file.write("Line 1\n")
    file.write("Line 2\n")
    file.write("Line 3\n")

print("File written and closed automatically!")

Why use 'with'?

  • Automatically closes file
  • Handles errors gracefully
  • Cleaner code
  • Prevents resource leaks

File Operations

Example 4: Reading Line by Line

# Method 1: readline()
with open("example.txt", "r") as file:
    line1 = file.readline()
    line2 = file.readline()
    print(f"Line 1: {line1.strip()}")
    print(f"Line 2: {line2.strip()}")

# Method 2: readlines()
with open("example.txt", "r") as file:
    lines = file.readlines()
    print(f"\nAll lines: {lines}")

# Method 3: Loop (most efficient)
print("\nLooping through file:")
with open("example.txt", "r") as file:
    for line in file:
        print(f"  {line.strip()}")

Example 5: Append Mode

# Append to existing file
with open("example.txt", "a") as file:
    file.write("Line 4 (appended)\n")
    file.write("Line 5 (appended)\n")

# Read to verify
with open("example.txt", "r") as file:
    print(file.read())

Example 6: File Existence Check

import os

filename = "example.txt"

if os.path.exists(filename):
    print(f"✓ {filename} exists")
    print(f"  Size: {os.path.getsize(filename)} bytes")
else:
    print(f"✗ {filename} does not exist")

Example 7: Exception Handling with Files

try:
    with open("nonexistent.txt", "r") as file:
        content = file.read()
        print(content)
except FileNotFoundError:
    print("✗ Error: File not found!")
except PermissionError:
    print("✗ Error: Permission denied!")
except Exception as e:
    print(f"✗ Error: {e}")

Example 8: Writing List to File

students = ["Alice", "Bob", "Charlie", "David"]

# Write list to file
with open("students.txt", "w") as file:
    for student in students:
        file.write(student + "\n")

# Read back
with open("students.txt", "r") as file:
    print("Students:")
    for line in file:
        print(f"  - {line.strip()}")

Example 9: CSV-like Data Handling

# Write CSV-like data
students = [
    ["Alice", "20", "A"],
    ["Bob", "21", "B"],
    ["Charlie", "22", "A"]
]

with open("students.csv", "w") as file:
    file.write("Name,Age,Grade\n")
    for student in students:
        file.write(",".join(student) + "\n")

# Read and parse
with open("students.csv", "r") as file:
    header = file.readline().strip()
    print(f"Header: {header}")
    print("\nData:")
    for line in file:
        name, age, grade = line.strip().split(",")
        print(f"  {name} is {age} years old, grade: {grade}")

Example 10: Copy File Content

source = "example.txt"
destination = "example_copy.txt"

try:
    with open(source, "r") as src:
        content = src.read()
    
    with open(destination, "w") as dest:
        dest.write(content)
    
    print(f"✓ Copied {source} to {destination}")
except FileNotFoundError:
    print(f"✗ Source file {source} not found")

Assessment

Test your understanding of dictionaries and file handling:

Question 1: Dictionary Access

What is safer: dict['key'] or dict.get('key')?

Answer: dict.get('key')

Explanation: get() returns None if key doesn't exist, while dict['key'] raises KeyError.

Question 2: Dictionary Method

What does dict.items() return?

Answer: Key-value pairs as tuples

Explanation: items() returns a view of (key, value) tuples.

Question 3: File Mode

Which mode overwrites existing file content?

Answer: 'w' (write mode)

Explanation: Write mode creates new file or overwrites existing content.

Question 4: File Closing

Why use 'with' statement for file handling?

Answer: Automatically closes file

Explanation: 'with' ensures file is closed even if errors occur.

Question 5: Dictionary Keys

Can dictionary keys be duplicated?

Answer: No

Explanation: Each key must be unique. Duplicate keys overwrite previous values.

Question 6: File Reading

What does file.read() return?

Answer: Entire file content as string

Explanation: read() reads and returns all file content at once.

Question 7: Dictionary Update

What happens with: d = {'a': 1}; d['a'] = 2?

Answer: Updates value to 2

Explanation: Assigning to existing key updates its value.

Question 8: Append Mode

What does 'a' mode do?

Answer: Adds content to end of file

Explanation: Append mode adds new content without deleting existing data.

Question 9: Dictionary Length

How to get number of key-value pairs in dictionary?

Answer: len(dict)

Explanation: len() returns the number of items in dictionary.

Question 10: File Lines

What does file.readlines() return?

Answer: List of lines

Explanation: readlines() returns a list where each element is a line from the file.

Key Takeaways

  • Dictionaries store key-value pairs for fast lookups
  • Use get() method for safe dictionary access
  • Dictionary keys must be unique and immutable
  • File handling enables permanent data storage
  • Always use 'with' statement for file operations
  • Choose correct file mode: 'r', 'w', or 'a'
  • Handle file exceptions to prevent crashes
  • Close files properly to avoid resource leaks
