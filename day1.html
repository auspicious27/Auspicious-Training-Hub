Day 1: Programming Foundations + Environment Setup

Understanding how computers think and setting up your Python environment

Introduction

Welcome to Day 1 of your programming journey! Today, we'll explore the fundamental concepts of programming and set up your Python development environment. By the end of this day, you'll understand how computers solve problems and write your first Python program.

Hour 1: Programming Logic & Computational Thinking

What is Programming?

Programming is the process of creating a set of instructions that tell a computer how to perform a task. It's like writing a recipe for a computer to follow.

Purpose of Programming:

  • Automation: Perform repetitive tasks quickly and accurately
  • Problem Solving: Break down complex problems into manageable steps
  • Data Processing: Analyze and manipulate large amounts of information
  • Communication: Enable different systems to work together

Real-World Example:

Think of an ATM machine. When you withdraw money, the program:

  1. Verifies your PIN
  2. Checks your account balance
  3. Dispenses the requested amount
  4. Updates your balance
  5. Prints a receipt

Each step is a programmed instruction!

How Computers Solve Problems

Computers are incredibly fast but fundamentally simple machines. They can only:

  • Perform basic arithmetic operations (+, -, ×, ÷)
  • Store and retrieve data from memory
  • Make simple comparisons (is A greater than B?)
  • Repeat instructions

Key Insight: The power of computers comes from executing billions of these simple operations per second, not from being "smart."

Computational Thinking

Computational thinking is a problem-solving approach that involves breaking down complex problems into smaller, manageable parts that can be solved systematically.

Four Pillars of Computational Thinking:

1. Decomposition

Breaking a complex problem into smaller, more manageable sub-problems.

Example: Making a sandwich
  • Get bread
  • Get ingredients
  • Assemble sandwich
  • Cut and serve
2. Pattern Recognition

Identifying similarities or patterns in problems.

Example: Calculating area
  • Rectangle: length × width
  • Square: side × side
  • Pattern: multiply two dimensions
3. Abstraction

Focusing on important information and ignoring irrelevant details.

Example: A map
  • Shows roads and landmarks
  • Ignores individual trees, houses
  • Focuses on what's needed for navigation
4. Algorithm Design

Creating step-by-step instructions to solve the problem.

Example: Making tea
  1. Boil water
  2. Put tea bag in cup
  3. Pour hot water
  4. Wait 3 minutes
  5. Remove tea bag
  6. Add sugar/milk (optional)

Input–Process–Output (IPO) Model

Every computer program follows the IPO model:

INPUT

Data provided to the program

  • User input
  • File data
  • Sensor data
→

PROCESS

Operations performed on data

  • Calculations
  • Comparisons
  • Transformations
→

OUTPUT

Results produced

  • Display on screen
  • Save to file
  • Send to device

IPO Example: Calculator Program

Input: Two numbers (5 and 3) and an operation (+)

Process: Add the two numbers (5 + 3)

Output: Display result (8)

Program Execution Flow

Programs execute instructions in a specific order:

1. Sequential Flow

Instructions execute one after another, top to bottom

print("Step 1")
print("Step 2")
print("Step 3")

2. Conditional Flow

Instructions execute based on conditions

if age >= 18:
    print("You can vote")
else:
    print("You cannot vote yet")

3. Iterative Flow

Instructions repeat multiple times

for i in range(5):
    print("Count:", i)

Human Thinking vs Computer Logic

Human Thinking Computer Logic
Can understand context and ambiguity Requires precise, unambiguous instructions
Can make assumptions Cannot assume anything not explicitly stated
Learns from experience Follows programmed instructions exactly
Can handle incomplete information Needs complete data to process
Relatively slow at calculations Extremely fast at calculations
Gets tired and makes mistakes Never tires, consistent results

Example of Precision Needed:

Human instruction: "Make me a cup of tea"

A human understands this means: boil water, add tea bag, pour water, wait, remove bag, etc.

Computer instruction: Must specify every single step:

  1. Fill kettle with 250ml water
  2. Turn on kettle
  3. Wait until water temperature = 100°C
  4. Place tea bag in cup
  5. Pour water into cup
  6. Wait 180 seconds
  7. Remove tea bag

Programming languages bridge the gap between human thinking and computer execution.

Why Python?

  • High demand in job market

Hour 2: Python Environment Setup + Basic Syntax

What is Python?

Python is a high-level, interpreted programming language created by Guido van Rossum in 1991. It emphasizes code readability and simplicity.

Key Characteristics:

  • Interpreted: Code runs line by line (no compilation needed)
  • Dynamically Typed: No need to declare variable types
  • Object-Oriented: Supports OOP concepts
  • Cross-Platform: Runs on Windows, Mac, Linux
  • Extensive Libraries: Thousands of pre-built modules

What is Anaconda?

Anaconda is a free, open-source distribution of Python and R for scientific computing and data science.

Why Use Anaconda?

  • Package Management: Comes with 250+ pre-installed packages (NumPy, Pandas, Matplotlib, etc.)
  • Environment Management: Create isolated environments for different projects
  • Cross-Platform: Works on Windows, Mac, and Linux
  • Anaconda Navigator: GUI for managing packages and environments
  • Jupyter Notebook: Interactive coding environment included
  • No Admin Rights Needed: Can be installed without administrator privileges

Anaconda Installation Steps (Conceptual)

  1. Download Anaconda:

    Visit anaconda.com/download

    Choose your operating system (Windows/Mac/Linux)

    Download the installer (typically 500-700 MB)

  2. Run the Installer:

    Double-click the downloaded file

    Follow the installation wizard

  3. Select Installation Location:

    Use default location or choose custom path

    Ensure sufficient disk space (3-5 GB)

  4. Advanced Options:

    ✓ Register Anaconda as default Python (recommended for beginners)

    ✓ Add Anaconda to PATH environment variable (optional)

  5. Complete Installation:

    Wait for installation to complete (5-10 minutes)

    Click "Finish"

  6. Verify Installation:

    Open Anaconda Navigator from Start Menu/Applications

    You should see various tools including Jupyter Notebook

Introduction to Jupyter Notebook

Jupyter Notebook is an open-source web application that allows you to create and share documents containing live code, equations, visualizations, and narrative text.

Why Use Jupyter Notebook?

  • Interactive: Run code and see results immediately
  • Documentation: Mix code with explanatory text and images
  • Visualization: Display graphs and charts inline
  • Experimentation: Test code snippets without creating full programs
  • Sharing: Easy to share notebooks with others
  • Learning: Perfect for tutorials and educational content

How Jupyter Notebook Works

1. Notebook (.ipynb file)

A document that contains cells of different types

2. Cells

Building blocks of a notebook:

  • Code Cells: Contain executable Python code
  • Markdown Cells: Contain formatted text, headings, lists
  • Raw Cells: Unformatted text (rarely used)
3. Kernel

The computational engine that executes code (Python 3 in our case)

4. Output

Results displayed below code cells (text, numbers, graphs, tables)

Launching Jupyter Notebook (Conceptual Flow)

Method 1: Using Anaconda Navigator (Easiest)
  1. Open Anaconda Navigator
  2. Find "Jupyter Notebook" tile
  3. Click "Launch" button
  4. Browser opens automatically with Jupyter interface
  5. Navigate to desired folder
  6. Click "New" → "Python 3" to create a notebook
Method 2: Using Command Line
  1. Open Terminal (Mac/Linux) or Anaconda Prompt (Windows)
  2. Navigate to your working directory: cd Documents/Python
  3. Type: jupyter notebook
  4. Press Enter
  5. Browser opens with Jupyter interface

Structure of a Python Program in Jupyter

Basic Program Structure:

Cell 1: Comments and Documentation
# This is a comment - explains what the code does
# Comments start with # and are ignored by Python
# Use comments to make your code understandable

"""
This is a multi-line comment (docstring)
Used for longer explanations
"""
Cell 2: Variable Declarations
# Storing data in variables
name = "Alice"
age = 25
height = 5.6
is_student = True
Cell 3: Processing/Calculations
# Performing operations
birth_year = 2024 - age
height_in_cm = height * 30.48
Cell 4: Output
# Displaying results
print("Name:", name)
print("Age:", age)
print("Birth Year:", birth_year)

Python Syntax Rules

1. Case Sensitivity

Python is case-sensitive. Name, name, and NAME are different variables.

name = "Alice"
Name = "Bob"
print(name)  # Output: Alice
print(Name)  # Output: Bob

2. Indentation (CRITICAL!)

Python uses indentation (spaces/tabs) to define code blocks. Most languages use braces { }.

# Correct indentation
if age >= 18:
    print("Adult")      # 4 spaces indentation
    print("Can vote")   # Same level

# Wrong indentation (will cause error)
if age >= 18:
print("Adult")  # Error: expected indented block

⚠️ Important: Use either 4 spaces OR 1 tab consistently. Don't mix them!

3. Comments

Use # for single-line comments, """ """ for multi-line comments

# This is a single-line comment

"""
This is a
multi-line comment
"""

x = 5  # You can also add comments after code

4. Statements

Each statement typically goes on a new line. No semicolon needed!

# Correct
x = 5
y = 10
z = x + y

# Also valid (but not recommended)
x = 5; y = 10; z = x + y

5. Line Continuation

Use backslash \ to continue long lines

# Long line broken into multiple lines
total = 1 + 2 + 3 + \
        4 + 5 + 6

# Or use parentheses (preferred)
total = (1 + 2 + 3 +
         4 + 5 + 6)

6. Naming Conventions

  • Variable names: lowercase with underscores: my_variable
  • Function names: lowercase with underscores: calculate_total()
  • Class names: CapitalizedWords: MyClass
  • Constants: UPPERCASE: MAX_SIZE
# Good naming
student_name = "Alice"
total_marks = 95
MAX_ATTEMPTS = 3

# Bad naming (but valid)
x = "Alice"
tm = 95
ma = 3

Understanding a Simple Python Program Line by Line

Example 1: Hello World Program

# My first Python program
print("Hello, World!")

Line 1: # My first Python program

  • This is a comment (starts with #)
  • Python ignores this line
  • Used to explain what the code does

Line 2: print("Hello, World!")

  • print() is a built-in function that displays output
  • "Hello, World!" is a string (text) in quotes
  • This line displays: Hello, World!
Output: 
Hello, World!

Example 2: Simple Calculator

# Simple addition program
num1 = 10
num2 = 20
sum = num1 + num2
print("The sum is:", sum)

Line 1: # Simple addition program

  • Comment describing the program

Line 2: num1 = 10

  • Creates a variable named num1
  • Assigns the value 10 to it
  • = is the assignment operator

Line 3: num2 = 20

  • Creates another variable num2 with value 20

Line 4: sum = num1 + num2

  • Adds num1 (10) and num2 (20)
  • Stores the result (30) in variable sum

Line 5: print("The sum is:", sum)

  • Displays the text "The sum is:" followed by the value of sum
  • Comma separates multiple items to print
Output: 
The sum is: 30

Example 3: User Input Program

# Program to greet user by name
name = input("Enter your name: ")
print("Hello,", name)
print("Welcome to Python programming!")

Line 2: name = input("Enter your name: ")

  • input() function asks user to type something
  • Displays the message "Enter your name: "
  • Waits for user to type and press Enter
  • Stores what user typed in variable name

Line 3: print("Hello,", name)

  • Displays "Hello," followed by the user's name
Sample Run: 
Enter your name: Alice
Hello, Alice
Welcome to Python programming!

Example 4: Complete IPO Model Program

# Program to calculate rectangle area
# INPUT
length = float(input("Enter length: "))
width = float(input("Enter width: "))

# PROCESS
area = length * width
perimeter = 2 * (length + width)

# OUTPUT
print("Area of rectangle:", area)
print("Perimeter of rectangle:", perimeter)

INPUT Section:

  • float() converts input text to decimal number
  • Gets length and width from user

PROCESS Section:

  • Calculates area: length × width
  • Calculates perimeter: 2 × (length + width)

OUTPUT Section:

  • Displays calculated area and perimeter
Sample Run: 
Enter length: 5
Enter width: 3
Area of rectangle: 15.0
Perimeter of rectangle: 16.0

Exercise 3: Simple Interest Calculator

Calculate simple interest. Formula: SI = (P × R × T) / 100

Show Solution
