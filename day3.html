Hour 1: Conditional Statements

Need for Decision Making in Programs

Real-world applications need to make decisions based on different conditions. For example:

Real-World Examples:

  • ATM: "If PIN is correct, allow withdrawal, else show error"

if Statement

The if statement executes a block of code only when a condition is True.

Syntax:

if condition:
    # This code runs only if condition is True
    statement1
    statement2

Important: Python uses indentation (4 spaces or 1 tab) to define code blocks. This is different from languages like C++ or Java that use curly braces { }.

Example 1: Check Voting Eligibility

# Check if person can vote
age = 20

if age >= 18:
    print("You are eligible to vote")
    print("Please register if you haven't already")

Line 2: age = 20

  • We store the age value

Line 4: if age >= 18:

  • Checks if age is greater than or equal to 18
  • The colon (:) is mandatory
  • If True, execute indented code below
Output: 
You are eligible to vote
Please register if you haven't already

if-else Statement

The if-else statement provides an alternative path when the condition is False.

Syntax:

if condition:
    # Code if condition is True
else:
    # Code if condition is False

Real-World Analogy:

Think of a traffic light:

  • If light is green → Cross the road
  • Else (if not green) → Wait

Example 1: Even or Odd Number

number = int(input("Enter a number: "))

if number % 2 == 0:
    print(f"{number} is an even number")
    print("Even numbers are divisible by 2")
else:
    print(f"{number} is an odd number")
    print("Odd numbers leave remainder 1 when divided by 2")

How it works:

  • If number % 2 == 0 is True → number is even
  • If number % 2 == 0 is False → number is odd
  • Only ONE block executes (either if or else)
Sample Run 1: 
Enter a number: 10
10 is an even number
Even numbers are divisible by 2
Sample Run 2: 
Enter a number: 7
7 is an odd number
Odd numbers leave remainder 1 when divided by 2

if-elif-else Ladder

The elif (else if) allows checking multiple conditions in sequence. Python checks each condition from top to bottom and executes the first True block.

Syntax:

if condition1:
    # Code if condition1 is True
elif condition2:
    # Code if condition2 is True
elif condition3:
    # Code if condition3 is True
else:
    # Code if all conditions are False

Key Points:

  • You can have multiple elif statements
  • else is optional
  • Only ONE block executes (the first True condition)
  • Once a condition is True, remaining conditions are not checked

Example 1: Grade Calculator

marks = 85

if marks >= 90:
                            grade = "A+"
    message = "Outstanding! Excellent performance!"
elif marks >= 80:
    grade = "A"
    message = "Very Good! Keep it up!"
elif marks >= 70:
    grade = "B"
    message = "Good! You can do better!"
elif marks >= 60:
    grade = "C"
    message = "Average. Need more effort!"
elif marks >= 40:
    grade = "D"
    message = "Pass. Work harder next time!"
else:
    grade = "F"
    message = "Fail. Don't give up, try again!"

print(f"Marks: {marks}")
print(f"Grade: {grade}")
print(f"Feedback: {message}")

How it works:

  • Checks if marks >= 90 → No (85 < 90)
  • Checks if marks >= 80 → Yes! (85 >= 80)
  • Executes this block and stops checking
  • Remaining elif and else are skipped
Output: 
Marks: 85
Grade: A
Feedback: Very Good! Keep it up!

Nested Conditional Statements

Nested conditionals are if statements inside other if statements. They allow complex decision-making with multiple levels of conditions.

Real-World Analogy:

Loan approval process:

  • First check: Is age >= 21?
  • If yes, second check: Is income >= ₹30,000?
  • If yes, third check: Is credit score >= 700?
  • If all yes: Approve loan

Example 1: Loan Eligibility Checker

age = 30
income = 50000
credit_score = 750

print("Checking loan eligibility...")
print("-" * 40)

if age >= 21:
    print("✓ Age requirement met")
    
    if income >= 30000:
        print("✓ Income requirement met")
        
        if credit_score >= 700:
            print("✓ Credit score requirement met")
            print("\n🎉 LOAN APPROVED!")
            print("You meet all eligibility criteria")
        else:
            print("✗ Credit score too low")
            print(f"Your score: {credit_score}")
            print("Required: 700 or above")
            print("\n❌ LOAN REJECTED")
    else:
        print("✗ Income too low")
        print(f"Your income: ₹{income}")
        print("Required: ₹30,000 or above")
        print("\n❌ LOAN REJECTED")
else:
    print("✗ Age requirement not met")
    print(f"Your age: {age}")
    print("Required: 21 or above")
    print("\n❌ LOAN REJECTED")
Output: 
Checking loan eligibility...
----------------------------------------
✓ Age requirement met
✓ Income requirement met
✓ Credit score requirement met

🎉 LOAN APPROVED!
You meet all eligibility criteria

⚠️ Best Practice: Avoid Deep Nesting

Too many nested levels make code hard to read. Instead of:

# Bad: Too many nested levels
if age >= 21:
    if income >= 30000:
        if credit_score >= 700:
            if employment_years >= 2:
                print("Approved")

Use logical operators:

# Good: Using logical operators
if age >= 21 and income >= 30000 and credit_score >= 700 and employment_years >= 2:
    print("Approved")

Hour 2: Program Structure & Logic Design

Structured Programming Concept

Structured programming is an approach that emphasizes breaking programs into clear, logical sections with proper organization.

Principles of Structured Programming:

  • Sequence: Instructions execute in order
  • Selection: Choose between alternatives (if-else)
  • Iteration: Repeat instructions (loops)
  • Modularity: Break into smaller parts (functions)

Example: Well-Structured Program

# ============================================
# PROGRAM: Student Grade Calculator
# AUTHOR: Your Name
# DATE: 2024
# ============================================

# INPUT SECTION
print("=" * 50)
print("STUDENT GRADE CALCULATOR")
print("=" * 50)

student_name = input("Enter student name: ")
marks = float(input("Enter marks (0-100): "))
attendance = float(input("Enter attendance %: "))

# VALIDATION SECTION
if marks < 0 or marks > 100:
    print("Error: Marks must be between 0 and 100")
elif attendance < 0 or attendance > 100:
    print("Error: Attendance must be between 0 and 100")
else:
    # PROCESSING SECTION
    if attendance >= 75:
        if marks >= 90:
            grade = "A+"
        elif marks >= 80:
            grade = "A"
        elif marks >= 70:
            grade = "B"
        elif marks >= 60:
            grade = "C"
        elif marks >= 40:
            grade = "D"
        else:
            grade = "F"
    else:
        grade = "F (Low Attendance)"
    
    # OUTPUT SECTION
    print("\n" + "=" * 50)
    print("RESULT")
    print("=" * 50)
    print(f"Student Name: {student_name}")
    print(f"Marks: {marks}")
    print(f"Attendance: {attendance}%")
    print(f"Grade: {grade}")
    print("=" * 50)

Code Blocks and Indentation

Python uses indentation to define code blocks. Consistent indentation is crucial!

⚠️ Common Indentation Errors:

# Error 1: No indentation
if age >= 18:
print("Adult")  # IndentationError!

# Error 2: Inconsistent indentation
if age >= 18:
    print("Adult")
      print("Can vote")  # IndentationError!

# Error 3: Mixing tabs and spaces
if age >= 18:
    print("Adult")  # 4 spaces
	print("Can vote")  # Tab - Error!

# Correct: Consistent indentation
if age >= 18:
    print("Adult")
    print("Can vote")

Role of Comments in Programs

Comments explain what code does, making it easier to understand.

Good Commenting Practice:

# Program: Calculate electricity bill
# Formula: 
#   0-100 units: ₹5 per unit
#   101-200 units: ₹7 per unit
#   Above 200: ₹10 per unit

units = int(input("Enter units consumed: "))

# Calculate bill based on slabs
if units <= 100:
    bill = units * 5
elif units <= 200:
    # First 100 at ₹5, remaining at ₹7
    bill = (100 * 5) + ((units - 100) * 7)
else:
    # First 100 at ₹5, next 100 at ₹7, remaining at ₹10
    bill = (100 * 5) + (100 * 7) + ((units - 200) * 10)

print(f"Total Bill: ₹{bill}")

Common Logical and Structural Mistakes

Mistake 1: Using = instead of ==

# Wrong
if age = 18:  # SyntaxError!
    print("Eighteen")

# Correct
if age == 18:
    print("Eighteen")

Mistake 2: Forgetting Colon

# Wrong
if age >= 18  # SyntaxError!
    print("Adult")

# Correct
if age >= 18:
    print("Adult")

Mistake 3: Wrong Condition Order

# Wrong - will never reach other conditions
if marks >= 40:
    grade = "D"
elif marks >= 90:  # Never reached!
    grade = "A+"

# Correct - check highest first
if marks >= 90:
    grade = "A+"
elif marks >= 40:
    grade = "D"

Planning Logic Before Writing Code

Always plan your logic before coding. Use flowcharts or pseudocode.

Example: Planning a Login System

Step 1: Write Pseudocode

1. Get username from user
2. Get password from user
3. IF username is correct:
       IF password is correct:
           Show "Login successful"
       ELSE:
           Show "Wrong password"
   ELSE:
       Show "Username not found"

correct_username = "admin"
correct_password = "pass123"

username = input("Enter username: ")

        print("Please try again")

    print("✗ Username not found")
    print("Please check your username")

Question 9: Conceptual

Explain the difference between if-elif-else and multiple if statements.

Show Answer

Difference:

if-elif-else: Only ONE block executes (the first True condition). Once a condition is True, remaining conditions are not checked.

Multiple if: ALL conditions are checked independently. Multiple blocks can execute.

# if-elif-else: Only prints "A"
x = 10
if x > 5:
    print("A")
elif x > 8:
    print("B")  # Not checked

# Multiple if: Prints both "A" and "B"
x = 10
if x > 5:
    print("A")
if x > 8:
    print("B")  # Also checked
