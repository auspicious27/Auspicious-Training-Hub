Day 2: Variables, Data Types, and Operators

Learn how to store and manipulate data in Python

Introduction

Today we'll explore the fundamental building blocks of Python programming: variables, data types, and operators. These concepts are essential for storing, organizing, and manipulating data in your programs.

Hour 1: Variables & Data Types

What are Variables?

A variable is a named container that stores data in computer memory. Think of it as a labeled box where you can put information and retrieve it later.

Purpose of Variables:

  • Storage: Hold data temporarily during program execution
  • Reusability: Use the same value multiple times without retyping
  • Flexibility: Change values as the program runs
  • Readability: Make code more understandable with meaningful names

Real-World Analogy:

Imagine a locker in a gym:

  • Locker Number: Variable name (e.g., "age")
  • Contents: Variable value (e.g., 25)
  • You can open the locker, check contents, or replace them

Creating Variables in Python

# Variable assignment syntax: variable_name = value
name = "Alice"
age = 25
height = 5.6
is_student = True

# Using variables
print(name)  # Output: Alice
print(age)   # Output: 25

Rules for Naming Variables

1. Must Start with Letter or Underscore

# Valid
name = "Alice"
_age = 25
user1 = "Bob"

# Invalid
1user = "Bob"  # Error: cannot start with number
@name = "Alice"  # Error: cannot use special characters

2. Can Contain Letters, Numbers, and Underscores

# Valid
student_name = "Alice"
age2 = 25
first_name_1 = "Bob"

# Invalid
student-name = "Alice"  # Error: hyphen not allowed
first name = "Bob"  # Error: space not allowed
user@email = "test"  # Error: @ not allowed

3. Case Sensitive

name = "Alice"
Name = "Bob"
NAME = "Charlie"

print(name)  # Alice
print(Name)  # Bob
print(NAME)  # Charlie
# These are three different variables!

4. Cannot Use Reserved Keywords

Python has reserved words that cannot be used as variable names:

if, else, elif, for, while, def, class, import, from, return, True, False, None, and, or, not, in, is, try, except, finally, with, as, pass, break, continue, lambda, yield 
# Invalid
if = 5  # Error: 'if' is a keyword
class = "Python"  # Error: 'class' is a keyword

# Valid alternatives
if_condition = 5
class_name = "Python"

5. Use Descriptive Names

# Bad (not descriptive)
x = 25
y = "Alice"
z = 5.6

# Good (descriptive)
age = 25
student_name = "Alice"
height_in_feet = 5.6

Best Practices for Variable Names:

  • Use lowercase with underscores: student_age
  • Be descriptive: total_price instead of tp
  • Avoid single letters except for counters: i, j, k
  • Use meaningful abbreviations: num_students instead of number_of_students_in_class

Data Types in Python

A data type defines what kind of value a variable can hold and what operations can be performed on it.

1. Integer (int)

Whole numbers without decimal points

# Integer examples
age = 25
year = 2024
temperature = -5
population = 1000000

print(type(age))  # Output: 

# Operations
x = 10
y = 3
print(x + y)  # 13
print(x - y)  # 7
print(x * y)  # 30
print(x // y)  # 3 (integer division)
Use Cases:
  • Counting items
  • Age, year, quantity
  • Array indices

2. Float (float)

Numbers with decimal points

# Float examples
height = 5.6
price = 19.99
temperature = 98.6
pi = 3.14159

print(type(height))  # Output: 

# Operations
x = 10.5
y = 2.5
print(x + y)  # 13.0
print(x / y)  # 4.2
print(x * y)  # 26.25
Use Cases:
  • Measurements (height, weight)
  • Prices and money
  • Scientific calculations

3. String (str)

Text data enclosed in quotes

# String examples
name = "Alice"
city = 'New York'
message = """This is a
multi-line string"""

print(type(name))  # Output: 

# String operations
first_name = "John"
last_name = "Doe"
full_name = first_name + " " + last_name  # Concatenation
print(full_name)  # John Doe

# String methods
text = "hello world"
print(text.upper())  # HELLO WORLD
print(text.capitalize())  # Hello world
print(len(text))  # 11 (length)
Use Cases:
  • Names, addresses
  • Messages and text
  • File paths

4. Boolean (bool)

True or False values

# Boolean examples
is_student = True
has_license = False
is_adult = True

print(type(is_student))  # Output: 

# Boolean from comparisons
age = 20
is_adult = age >= 18
print(is_adult)  # True

# Boolean operations
x = True
y = False
print(x and y)  # False
print(x or y)   # True
print(not x)    # False
Use Cases:
  • Conditional checks
  • Flags and switches
  • Validation results

Type Conversion

Type conversion (also called type casting) is the process of converting one data type to another.

Why Type Conversion is Needed

When you get input from a user, it's always a string. To perform calculations, you need to convert it:

# Without conversion (WRONG)
age = input("Enter age: ")  # User enters: 25
next_year_age = age + 1  # Error! Can't add string and number

# With conversion (CORRECT)
age = int(input("Enter age: "))  # Converts string to int
next_year_age = age + 1  # Works! 25 + 1 = 26
print(next_year_age)  # 26

Type Conversion Functions

Function Purpose Example
int() Convert to integer int("25") → 25
float() Convert to float float("3.14") → 3.14
str() Convert to string str(25) → "25"
bool() Convert to boolean bool(1) → True

Detailed Examples

String to Number Conversion
# String to int
age_str = "25"
age_int = int(age_str)
print(age_int + 5)  # 30

# String to float
price_str = "19.99"
price_float = float(price_str)
print(price_float * 2)  # 39.98

# Invalid conversion (causes error)
# invalid = int("hello")  # ValueError!
Number to String Conversion
# Int to string
age = 25
age_str = str(age)
message = "I am " + age_str + " years old"
print(message)  # I am 25 years old

# Float to string
price = 19.99
price_str = str(price)
print("Price: $" + price_str)  # Price: $19.99
Number Conversions
# Float to int (truncates decimal)
x = 3.7
y = int(x)
print(y)  # 3 (not 4!)

# Int to float
a = 5
b = float(a)
print(b)  # 5.0
Boolean Conversions
# Numbers to boolean
print(bool(0))    # False
print(bool(1))    # True
print(bool(-5))   # True
print(bool(100))  # True

# Strings to boolean
print(bool(""))      # False (empty string)
print(bool("Hello")) # True (non-empty string)

# Boolean to int
print(int(True))   # 1
print(int(False))  # 0

⚠️ Common Conversion Errors

# These will cause errors:
# int("3.14")  # ValueError: invalid literal
# int("hello")  # ValueError: invalid literal
# float("abc")  # ValueError: could not convert

# Solutions:
x = float("3.14")  # Use float() for decimals
y = int(float("3.14"))  # Convert to float first, then int

Hour 2: Operators

What are Operators?

Operators are special symbols that perform operations on variables and values. They are the building blocks for creating expressions and performing calculations.

Purpose of Operators:

  • Perform mathematical calculations
  • Compare values
  • Make logical decisions
  • Assign and modify values

Arithmetic Operators

Used to perform mathematical operations

Operator Name Example Result
+ Addition 5 + 3 8
- Subtraction 5 - 3 2
* Multiplication 5 * 3 15
/ Division 5 / 2 2.5
// Floor Division 5 // 2 2
% Modulus (Remainder) 5 % 2 1
** Exponentiation (Power) 5 ** 2 25

Detailed Examples

# Basic arithmetic
a = 10
b = 3

print(a + b)   # 13 (addition)
print(a - b)   # 7 (subtraction)
print(a * b)   # 30 (multiplication)
print(a / b)   # 3.333... (division - always returns float)
print(a // b)  # 3 (floor division - returns integer part)
print(a % b)   # 1 (modulus - returns remainder)
print(a ** b)  # 1000 (10 to the power of 3)

# Practical examples
# Calculate area of rectangle
length = 5
width = 3
area = length * width
print("Area:", area)  # 15

# Calculate average
num1 = 85
num2 = 90
num3 = 78
average = (num1 + num2 + num3) / 3
print("Average:", average)  # 84.333...

# Check if number is even or odd using modulus
number = 7
remainder = number % 2
print(remainder)  # 1 (odd number)
# If remainder is 0, number is even
# If remainder is 1, number is odd

Real-World Use Cases

  • Addition (+): Calculate total price, sum of scores
  • Subtraction (-): Calculate discount, age difference
  • Multiplication (*): Calculate total cost (price × quantity)
  • Division (/): Calculate average, split bill
  • Modulus (%): Check even/odd, find remainder, cycle through values
  • Exponentiation (**): Calculate compound interest, area of circle

Relational (Comparison) Operators

Used to compare two values. Always return True or False

Operator Name Example Result
== Equal to 5 == 5 True
!= Not equal to 5 != 3 True
> Greater than 5 > 3 True
< Less than 5 < 3 False
>= Greater than or equal to 5 >= 5 True
<= Less than or equal to 5 <= 3 False

Detailed Examples

# Comparison examples
age = 20
passing_marks = 40
marks = 45

# Equal to
print(age == 20)  # True
print(age == 25)  # False

# Not equal to
print(age != 25)  # True
print(age != 20)  # False

# Greater than
print(marks > passing_marks)  # True (45 > 40)
print(marks > 50)  # False

# Less than
print(age < 30)  # True
print(age < 18)  # False

# Greater than or equal to
print(marks >= 40)  # True
print(marks >= 45)  # True
print(marks >= 50)  # False

# Less than or equal to
print(age <= 20)  # True
print(age <= 18)  # False

# Practical example: Check voting eligibility
age = 17
can_vote = age >= 18
print("Can vote:", can_vote)  # False

# Compare strings
name1 = "Alice"
name2 = "Bob"
print(name1 == name2)  # False
print(name1 != name2)  # True

⚠️ Common Mistake

Don't confuse = (assignment) with == (comparison)

# Assignment (stores value)
x = 5  # x now equals 5

# Comparison (checks equality)
result = (x == 5)  # result is True

# Wrong usage
# if x = 5:  # Error! Use == for comparison
if x == 5:  # Correct!

Logical Operators

Used to combine multiple conditions. Return True or False

Operator Description Example Result
and True if both conditions are True True and True True
or True if at least one condition is True True or False True
not Reverses the boolean value not True False

AND Operator

Returns True only if BOTH conditions are True

# Truth table for AND
print(True and True)    # True
print(True and False)   # False
print(False and True)   # False
print(False and False)  # False

# Practical example
age = 25
has_license = True
can_drive = age >= 18 and has_license
print(can_drive)  # True (both conditions met)

age = 16
has_license = True
can_drive = age >= 18 and has_license
print(can_drive)  # False (age condition not met)

OR Operator

Returns True if AT LEAST ONE condition is True

# Truth table for OR
print(True or True)    # True
print(True or False)   # True
print(False or True)   # True
print(False or False)  # False

# Practical example
is_weekend = True
is_holiday = False
can_relax = is_weekend or is_holiday
print(can_relax)  # True (one condition met)

is_weekend = False
is_holiday = False
can_relax = is_weekend or is_holiday
print(can_relax)  # False (no condition met)

NOT Operator

Reverses the boolean value

# Truth table for NOT
print(not True)   # False
print(not False)  # True

# Practical example
is_raining = False
go_outside = not is_raining
print(go_outside)  # True

is_raining = True
go_outside = not is_raining
print(go_outside)  # False

Complex Logical Expressions

# Combining multiple operators
age = 25
income = 50000
has_job = True

# Check loan eligibility
eligible = age >= 21 and income >= 30000 and has_job
print("Loan eligible:", eligible)  # True

# Check discount eligibility (student OR senior citizen)
is_student = False
age = 70
gets_discount = is_student or age >= 65
print("Gets discount:", gets_discount)  # True

# Complex condition
temperature = 25
is_sunny = True
is_weekend = True

# Perfect day for picnic
perfect_day = temperature >= 20 and temperature <= 30 and is_sunny and is_weekend
print("Perfect for picnic:", perfect_day)  # True

Assignment Operators

Used to assign values to variables

Operator Example Equivalent To Description
= x = 5 x = 5 Assign value
+= x += 3 x = x + 3 Add and assign
-= x -= 3 x = x - 3 Subtract and assign
*= x *= 3 x = x * 3 Multiply and assign
/= x /= 3 x = x / 3 Divide and assign
//= x //= 3 x = x // 3 Floor divide and assign
%= x %= 3 x = x % 3 Modulus and assign
**= x **= 3 x = x ** 3 Exponent and assign

Detailed Examples

# Basic assignment
x = 10
print(x)  # 10

# Add and assign
x += 5  # Same as: x = x + 5
print(x)  # 15

# Subtract and assign
x -= 3  # Same as: x = x - 3
print(x)  # 12

# Multiply and assign
x *= 2  # Same as: x = x * 2
print(x)  # 24

# Divide and assign
x /= 4  # Same as: x = x / 4
print(x)  # 6.0

# Practical examples
# Counter
count = 0
count += 1  # Increment by 1
count += 1
count += 1
print("Count:", count)  # 3

# Shopping cart total
total = 0

total += 29.99  # Add item 2

# Apply discount
total *= 0.9  # 10% discount (multiply by 0.9)

Operator Precedence

Operator precedence determines the order in which operations are performed in an expression.

Precedence Order (Highest to Lowest):

  1. () - Parentheses
  2. ** - Exponentiation
  3. *, /, //, % - Multiplication, Division, Floor Division, Modulus
  4. +, - - Addition, Subtraction
  5. ==, !=, >, <, >=, <= - Comparison operators
  6. not - Logical NOT
  7. and - Logical AND
  8. or - Logical OR

Examples of Precedence

# Without parentheses
result = 2 + 3 * 4
print(result)  # 14 (not 20!)
# Explanation: 3 * 4 = 12, then 2 + 12 = 14

# With parentheses
result = (2 + 3) * 4
print(result)  # 20
# Explanation: 2 + 3 = 5, then 5 * 4 = 20

# Complex expression
result = 10 + 5 * 2 - 3
print(result)  # 17
# Step 1: 5 * 2 = 10
# Step 2: 10 + 10 = 20
# Step 3: 20 - 3 = 17

# With parentheses for clarity
result = 10 + (5 * 2) - 3
print(result)  # 17 (same result, but clearer)

# Exponentiation has higher precedence
result = 2 + 3 ** 2
print(result)  # 11 (not 25!)
# Explanation: 3 ** 2 = 9, then 2 + 9 = 11

# Comparison and logical operators
age = 25
income = 50000
result = age >= 18 and income >= 30000
print(result)  # True
# Step 1: age >= 18 = True
# Step 2: income >= 30000 = True
# Step 3: True and True = True

Best Practice: Use Parentheses

Even when not required, use parentheses to make your code clearer:

# Less clear
total = price * quantity + tax - discount

# More clear
total = (price * quantity) + tax - discount

# Even clearer
total = ((price * quantity) + tax) - discount

Expression Evaluation

An expression is a combination of values, variables, and operators that produces a result.

Step-by-Step Evaluation

# Complex expression
a = 5
b = 3
c = 2

result = a + b * c ** 2 - 10 / 2

# Step-by-step evaluation:
# Step 1: c ** 2 = 2 ** 2 = 4
# Step 2: b * 4 = 3 * 4 = 12
# Step 3: 10 / 2 = 5.0
# Step 4: a + 12 = 5 + 12 = 17
# Step 5: 17 - 5.0 = 12.0

print(result)  # 12.0

Real-World Example: Calculate Final Price

# Calculate final price with tax and discount
original_price = 100
quantity = 3
discount_percent = 10
tax_percent = 8

# Calculate step by step
subtotal = original_price * quantity
print("Subtotal:", subtotal)  # 300

discount_amount = subtotal * discount_percent / 100
print("Discount:", discount_amount)  # 30.0

price_after_discount = subtotal - discount_amount
print("After discount:", price_after_discount)  # 270.0

tax_amount = price_after_discount * tax_percent / 100
print("Tax:", tax_amount)  # 21.6

final_price = price_after_discount + tax_amount
print("Final price:", final_price)  # 291.6

# Or in one expression (with parentheses for clarity)
final_price = ((original_price * quantity) * (1 - discount_percent/100)) * (1 + tax_percent/100)
print("Final price:", final_price)  # 291.6

Question 3: Code Analysis

What will be the output of this code?

x = 10
y = 3
print(x // y)
Show Answer

Answer: 3

The // operator performs floor division, which returns only the integer part of the division (10 ÷ 3 = 3 remainder 1, so result is 3).

Question 4: Multiple Choice

What does the modulus operator (%) return?

Show Answer

Answer: B) The remainder of division

The modulus operator (%) returns the remainder after division. For example, 7 % 3 = 1.

Question 5: True/False

The expression 5 > 3 and 2 < 1 evaluates to True.

Show Answer

Answer: False

5 > 3 is True, but 2 < 1 is False. The 'and' operator requires BOTH conditions to be True, so the result is False.

Question 6: Code Analysis

What will be the value of x after this code?

x = 10
x += 5
x *= 2
Show Answer

Answer: 30

Step 1: x = 10
Step 2: x += 5 → x = 10 + 5 = 15
Step 3: x *= 2 → x = 15 * 2 = 30

Question 7: Multiple Choice

What is the result of 2 + 3 * 4?

Show Answer

Answer: B) 14

Due to operator precedence, multiplication is performed first: 3 * 4 = 12, then 2 + 12 = 14.

Question 8: Fill in the Blank

To convert a string to an integer in Python, we use the __________ function.

Show Answer

Answer: int()

The int() function converts a string or float to an integer. Example: int("25") returns 25.

Question 10: Practical Challenge
