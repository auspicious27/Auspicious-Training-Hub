Hour 1: Sorting Algorithms

Why Sorting is Needed

Sorting arranges data in a specific order (ascending or descending). It's fundamental to many algorithms.

Real-World Examples:

  • Phone contacts: Sorted alphabetically
  • E-commerce: Sort by price, rating
  • Search engines: Sort results by relevance
  • Databases: Faster queries on sorted data

Benefits of Sorting:

  • Enables binary search (O(log n))
  • Makes data easier to understand
  • Helps find duplicates
  • Required for many algorithms

Bubble Sort

Bubble sort repeatedly compares adjacent elements and swaps them if they're in wrong order. Largest element "bubbles up" to the end.

Algorithm:

  1. Compare adjacent elements
  2. Swap if first > second
  3. Repeat for all elements
  4. After each pass, largest element reaches end
  5. Repeat n-1 times

Example 1: Bubble Sort Visualization

# Bubble Sort Step-by-Step
"""
Initial: [64, 34, 25, 12, 22]

Pass 1:
[34, 64, 25, 12, 22] - swap 64 and 34
[34, 25, 64, 12, 22] - swap 64 and 25
[34, 25, 12, 64, 22] - swap 64 and 12
[34, 25, 12, 22, 64] - swap 64 and 22 (64 in place!)

Pass 2:
[25, 34, 12, 22, 64] - swap 34 and 25
[25, 12, 34, 22, 64] - swap 34 and 12
[25, 12, 22, 34, 64] - swap 34 and 22 (34 in place!)

... continues until sorted
"""

Example 2: Bubble Sort Implementation

def bubble_sort(arr):
    """
    Bubble Sort Algorithm
    Time Complexity: O(n²)
    Space Complexity: O(1)
    """
    n = len(arr)
    
    # Outer loop for passes
    for i in range(n):
        # Inner loop for comparisons
        for j in range(n - i - 1):
            # Swap if element is greater than next
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    
    return arr

# Test
numbers = [64, 34, 25, 12, 22, 11, 90]
print(f"Original: {numbers}")
sorted_numbers = bubble_sort(numbers.copy())
print(f"Sorted: {sorted_numbers}")
Output: 
Original: [64, 34, 25, 12, 22, 11, 90]
Sorted: [11, 12, 22, 25, 34, 64, 90]

Example 3: Optimized Bubble Sort

def bubble_sort_optimized(arr):
    """
    Optimized version - stops if no swaps made
    Best case: O(n) when already sorted
    """
    n = len(arr)
    
    for i in range(n):
        swapped = False
        
        for j in range(n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        
        # If no swaps, array is sorted
        if not swapped:
            break
    
    return arr

# Test with already sorted array
numbers = [1, 2, 3, 4, 5]
print(f"Already sorted: {numbers}")
result = bubble_sort_optimized(numbers.copy())
print(f"Result: {result}")

Bubble Sort Complexity:

  • Best Case: O(n) - already sorted (optimized version)
  • Average Case: O(n²)
  • Worst Case: O(n²) - reverse sorted
  • Space: O(1) - in-place sorting

Selection Sort

Selection sort finds the minimum element and places it at the beginning. Repeats for remaining elements.

Algorithm:

  1. Find minimum element in unsorted part
  2. Swap it with first unsorted element
  3. Move boundary of sorted part
  4. Repeat until all elements sorted

Example 4: Selection Sort Implementation

def selection_sort(arr):
    """
    Selection Sort Algorithm
    Time Complexity: O(n²)
    Space Complexity: O(1)
    """
    n = len(arr)
    
    for i in range(n):
        # Find minimum in remaining array
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        
        # Swap minimum with first unsorted element
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    
    return arr

# Test
numbers = [64, 25, 12, 22, 11]
print(f"Original: {numbers}")
sorted_numbers = selection_sort(numbers.copy())
print(f"Sorted: {sorted_numbers}")
Output: 
Original: [64, 25, 12, 22, 11]
Sorted: [11, 12, 22, 25, 64]

Example 5: Comparing Sorting Algorithms

import time

def compare_sorts(arr):
    """Compare bubble and selection sort"""
    # Bubble sort
    arr1 = arr.copy()
    start = time.time()
    bubble_sort(arr1)
    bubble_time = time.time() - start
    
    # Selection sort
    arr2 = arr.copy()
    start = time.time()
    selection_sort(arr2)
    selection_time = time.time() - start
    
    print(f"Bubble Sort: {bubble_time:.6f}s")
    print(f"Selection Sort: {selection_time:.6f}s")

# Test
numbers = [64, 34, 25, 12, 22, 11, 90, 88, 45, 50]
compare_sorts(numbers)

Sorting Algorithms Comparison:

Algorithm Best Average Worst Space
Bubble Sort O(n) O(n²) O(n²) O(1)
Selection Sort O(n²) O(n²) O(n²) O(1)

Hour 2: Linked Lists

What is a Linked List?

A linked list is a linear data structure where elements (nodes) are connected using pointers. Each node contains data and a reference to the next node.

Real-World Analogy:

Think of a treasure hunt:

  • Each clue (node) has information (data)
  • Each clue points to next location (next pointer)
  • Follow clues one by one to reach end

Node Structure:

Node:
┌──────┬──────┐
│ Data │ Next │
└──────┴──────┘

Linked List:
[10|•]→[20|•]→[30|•]→[40|None]
Head                    Tail

Example 6: Node Class

class Node:
    """Node class for linked list"""
    def __init__(self, data):
        self.data = data
        self.next = None

# Create nodes
node1 = Node(10)
node2 = Node(20)
node3 = Node(30)

# Link nodes
node1.next = node2
node2.next = node3

# Traverse
current = node1
while current:
    print(current.data, end=" → ")
    current = current.next
print("None")
Output: 
10 → 20 → 30 → None

Array vs Linked List:

Feature Array Linked List
Size Fixed Dynamic
Memory Contiguous Non-contiguous
Access O(1) O(n)
Insertion O(n) O(1) at head
Deletion O(n) O(1) at head

Linked List Operations

Example 7: Linked List Class

class LinkedList:
    """Singly Linked List implementation"""
    def __init__(self):
        self.head = None
    
    def is_empty(self):
        """Check if list is empty"""
        return self.head is None
    
    def display(self):
        """Display all elements"""
        if self.is_empty():
            print("List is empty")
            return
        
        current = self.head
        while current:
            print(current.data, end=" → ")
            current = current.next
        print("None")

# Test
ll = LinkedList()
print(f"Is empty: {ll.is_empty()}")
ll.display()

Example 8: Insert at Beginning

class LinkedList:
    # ... previous code ...
    
    def insert_at_beginning(self, data):
        """Insert node at beginning - O(1)"""
        new_node = Node(data)
        new_node.next = self.head
        self.head = new_node

# Test
ll = LinkedList()
ll.insert_at_beginning(30)
ll.insert_at_beginning(20)
ll.insert_at_beginning(10)
ll.display()  # 10 → 20 → 30 → None

Example 9: Insert at End

class LinkedList:
    # ... previous code ...
    
    def insert_at_end(self, data):
        """Insert node at end - O(n)"""
        new_node = Node(data)
        
        if self.is_empty():
            self.head = new_node
            return
        
        current = self.head
        while current.next:
            current = current.next
        current.next = new_node

# Test
ll = LinkedList()
ll.insert_at_end(10)
ll.insert_at_end(20)
ll.insert_at_end(30)
ll.display()  # 10 → 20 → 30 → None

Example 10: Delete Node

class LinkedList:
    # ... previous code ...
    
    def delete_node(self, key):
        """Delete first occurrence of key"""
        if self.is_empty():
            return
        
        # If head needs to be deleted
        if self.head.data == key:
            self.head = self.head.next
            return
        
        # Find node to delete
        current = self.head
        while current.next:
            if current.next.data == key:
                current.next = current.next.next
                return
            current = current.next

# Test
ll = LinkedList()
ll.insert_at_end(10)
ll.insert_at_end(20)
ll.insert_at_end(30)
ll.display()  # 10 → 20 → 30 → None

ll.delete_node(20)
ll.display()  # 10 → 30 → None

Types of Linked Lists:

  • Singly Linked List: Each node points to next
  • Doubly Linked List: Each node points to next and previous
  • Circular Linked List: Last node points to first

Is bubble sort a stable sorting algorithm?

Answer: Yes

Explanation: Equal elements maintain their relative order.

Key Takeaways

  • Sorting arranges data in specific order
  • Bubble sort compares adjacent elements - O(n²)
  • Selection sort finds minimum repeatedly - O(n²)
  • Both are in-place sorting algorithms
  • Linked lists use nodes with data and pointers
  • Linked lists have dynamic size
  • Arrays have faster access, linked lists have faster insertion
  • Insert at head of linked list is O(1)
  • Linked list memory is non-contiguous
  • Choose data structure based on operations needed
